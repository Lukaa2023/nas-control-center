APPLICATIONS / ACCESS

Services

SERVICE DIRECTORY

Shortcuts to the applications running on your NAS. Local links are for your home network; Tailscale links are for private remote access. Each service keeps its own authentication.

Web terminal

Browser-based shell · ttyd

TAILSCALE ONLY · 8443

Open a terminal session from a device connected to your Tailscale network. This endpoint is private to your tailnet.

https://nas.tail02ce4c.ts.net:8443 ↗

VukyWeb

Hosted website · Docker

PUBLIC FUNNEL · 8080

The website container is published on port 8080 and served publicly through Tailscale Funnel. The NAS dashboard remains protected by its existing HTTP Basic Authentication.

http://192.168.100.13:8080 ↗
https://nas.tail02ce4c.ts.net ↗

Cockpit

Linux server management

WEB UI · 9090

Manage the host, inspect system resources and open the built-in terminal. Use the private Tailscale route when away from home.

https://192.168.100.13:9090 ↗
https://100.76.132.23:9090 ↗
A browser certificate warning may appear if Cockpit uses a self-signed certificate.

Portainer

Docker container management

WEB UI · 9443

Inspect and manage Docker containers, images, networks and volumes.

https://192.168.100.13:9443 ↗
https://100.76.132.23:9443 ↗

SMB file sharing

Network folders

TCP · 445
